## Where OMEGA holds it

| Rule | Code |
| --- | --- |
| a `chainedWindow` below the outer's catalogued window minimum, on a rolling-inner chain | `omega/validate.py` `validate_column`: `CHAINED_WINDOW_BELOW_MINIMUM` on `<path>.chainedWindow`, the platform's sentence |
| the joint bound (unchanged; re-measured note) | `omega/validate.py` `_rolling_chain_depth` |
| the main candle | `omega/types.py` `ANCHOR_TIMEFRAMES`, `omega/authoring.py` `THESIS_UNMEASURED_ANCHOR` (unchanged) |
| replay of every preview and stage, and the 161 / 171 identity | `tests/test_v0_14_1.py` |

The minimum is read from the served catalogue (`authoring.parameters.window.minimum` of the outer). On a chain that
does not take `chainedWindow` (distance / spread / relativeTo inners), the only finding stays `CHAINED_WINDOW_REFUSED`.
An omitted `chainedWindow` is the outer's default (20), which is never below its minimum.
